# Dulno - Gitlab

[![CI](https://github.com/taskwolf-net/taskwolf-gitlab/actions/workflows/ci.yml/badge.svg)](https://github.com/taskwolf-net/taskwolf-gitlab/actions/workflows/ci.yml)

This module implements the Gitlab functionality in Dulno. It offers customers the possibility to manage their own Gitlab instance or their officially created Gitlab account.
